# Pagina niet gevonden

De pagina die je zoekt bestaat niet (meer), of de link is verouderd.

- Ga naar de [startpagina](index.md).
- Gebruik de zoekfunctie rechtsboven.

Een pagina kan bij een nieuwe versie zijn verplaatst of hernoemd. Denk je dat dit een fout is, meld het dan als issue op GitHub.
